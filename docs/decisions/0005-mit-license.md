# 0005. MIT license

- **Status:** Accepted
- **Date:** 2026-10-26

## Context

The tools are meant to be open source and used by anyone writing assembly on a Mac.

## Decision

MIT, the same as the owner's other tools.

## Consequences

Anyone can use, embed, or fork the tools. Third-party data with other licenses (instruction tables, docs text) must be compatible; see [0010](0010-isa-source.md).

## Alternatives considered

- **Apache-2.0.** Adds a patent grant, but MIT matches the owner's other repos and is simpler.
